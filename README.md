## 🚀 Capstone Project
This project represents my main hands-on experience and applied learning.

### **IoT-Based Fish Aquarium Monitoring and Feeding System**
- Built an IoT-enabled automation system using **ESP32 microcontroller**
- Integrated sensors for environmental monitoring and system control
- Implemented **automated feeding and pH regulation**
- Enabled **real-time data synchronization** using Firebase
- Supported remote monitoring and configuration through mobile and web interfaces
- Designed a structured and reliable system workflow for daily operation

This project helped me understand **system integration, automation logic, cloud connectivity, and real-time data handling**.
